# 🎰 Lottery Bandit — Cyberpunk Edition

A sophisticated Cyberpunk-styled lottery simulator with advanced hot number algorithms and frequency analysis. Built through 5 versions of continuous improvement.

## 🚀 Live Demo
[View Live App](https://fluffy-cheesecake-d5e6c1.netlify.app)

## ✨ Features
- Hot and cold number algorithms
- Frequency analysis and tracking
- Multiple lottery game modes
- Number prediction engine
- Statistics and probability tracking
- PWA — installable on mobile devices
- Cyberpunk neon design with glitch effects

## 🛠️ Technologies Used
- HTML5
- CSS3 (Custom Cyberpunk theme)
- JavaScript (Vanilla)
- Progressive Web App (PWA)

## 📱 How To Use
1. Select your lottery game mode
2. Generate predicted numbers based on frequency analysis
3. Track hot and cold numbers
4. Compare predictions against results

## 🔄 Version History

- v2 — Added frequency tracking
- v3 — Hot/cold number algorithms
- v4 — Enhanced UI and statistics
- v5 — Advanced prediction engine
